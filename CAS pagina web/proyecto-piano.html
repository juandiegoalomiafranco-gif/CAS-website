Explicación

Por qué este proyecto

El piano es el instrumento más visual para entender la teoría musical. Escalas, acordes, intervalos — todo está frente a ti. Este proyecto nació de la necesidad de entender mejor la armonía para aplicarla tanto al bajo como a la batería.

Objetivo del Proyecto

Explorar el piano como herramienta de teoría musical aplicada: acordes, progresiones, y composición de melodías simples.
